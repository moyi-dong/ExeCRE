# Benchmark Setup

This folder is intended for the benchmark data used in our experiments.

If the benchmark data is not already available, please run:

```bash
cd ExeCRE
python setup.py
```

For GSM8K, the dataset from:
https://codeload.github.com/openai/grade-school-math/zip/refs/heads/master

For LivecodeBench, the dataset from:
https://github.com/LiveCodeBench/LiveCodeBench
